RflyTools APT repository

RflySim's tools for Linux: github.com/Dankwa-Wadie/rflysim-mac-linux. Installing a .deb from the Releases page sets this repository up automatically, so updates arrive with sudo apt upgrade. To add it by hand (Debian 12+, Ubuntu 22.04+):

sudo curl -fsSLo /usr/share/keyrings/rflytools-archive-keyring.gpg \
  https://dankwa-wadie.github.io/rflysim-mac-linux/apt/rflytools-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/rflytools-archive-keyring.gpg] https://dankwa-wadie.github.io/rflysim-mac-linux/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/rflytools.list
sudo apt update && sudo apt install rflytools
